# 👑 EMPIRE ERP V4 PREMIUM

## Império da Moda Online

Sistema ERP premium desenvolvido para gerenciamento completo de uma operação de moda online.

---

## 📌 Sobre o Projeto

O EMPIRE ERP é uma plataforma de gestão empresarial com foco em:

- Controle de produtos
- Gestão de clientes
- Vendas
- Financeiro
- Compras
- Fornecedores
- Relatórios
- Usuários
- Configurações

# 📂 Módulos do Sistema


## 🏠 Dashboard

Tela principal do EMPIRE ERP.

Funções:

- Visão geral do negócio
- Indicadores
- Resumo financeiro
- Atividades recentes



## 📦 Produtos

Controle de:

- Cadastro de produtos
- Categorias
- Estoque
- Valores
- Imagens



## 👥 Clientes

Controle de:

- Cadastro de clientes
- Histórico de compras
- Dados de contato



## 🛒 Vendas

Controle de:

- Pedidos
- Vendas realizadas
- Status dos pedidos



## 💰 Financeiro

Controle de:

- Entradas
- Saídas
- Saldo
- Fluxo financeiro



## 🚚 Compras

Controle de:

- Solicitações
- Pedidos de compra
- Histórico



## 🏭 Fornecedores

Controle de:

- Empresas fornecedoras
- Contatos
- Produtos fornecidos



## 📊 Relatórios

Relatórios:

- Vendas
- Produtos
- Financeiro
- Clientes



## 👤 Usuários

Controle de:

- Usuários do sistema
- Permissões
- Acessos



## ⚙ Configurações

Configurações:

- Empresa
- Sistema
- Preferências
